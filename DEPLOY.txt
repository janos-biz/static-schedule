ESG 일정/담당자 보드 — 개발 서버 설치 안내
====================================================

압축을 푼 폴더가 그대로 데이터 폴더입니다. 그 안의 plan-*.md 를 읽고 씁니다.


1) 편집 비밀번호 먼저 넣기  ※ 이걸 안 하면 /admin 이 열리지 않습니다
----------------------------------------------------
압축 파일에는 비밀번호가 들어 있지 않습니다. 푼 폴더에서:

    cp .env.example .env

.env 를 열어 ADMIN_PASSWORD= 뒤에 팀에 공유한 비밀번호를 적습니다.
(윈도우면 메모장으로 .env.example 을 열어 .env 로 저장하세요)

비밀번호를 바꿀 때도 이 파일만 고치면 됩니다. 서버를 다시 띄울 필요 없이
저장하는 즉시 적용됩니다. 대신 그때 로그인해 있던 사람은 다시 로그인해야 합니다.


2-A) docker 로 띄우기 (상시 운영 권장)
----------------------------------------------------
    docker compose up -d --build

- 서버가 재부팅돼도 자동으로 다시 뜹니다 (restart: unless-stopped)
- 로그: docker compose logs -f   종료: docker compose down


2-B) docker 없이 띄우기
----------------------------------------------------
node 만 있으면 됩니다. dist(빌드 결과물)가 이미 들어 있고
server/ 는 외부 라이브러리를 쓰지 않아 npm install 이 필요 없습니다.

    PLAN_DIR="$PWD" PORT=5180 node server/index.mjs

소스를 고쳐서 다시 빌드할 때만 npm install && npm run build 가 필요합니다.


3) 접속
----------------------------------------------------
    보기(비밀번호 없음)   http://<서버IP>:5180
    편집(비밀번호 필요)   http://<서버IP>:5180/admin

- 보기 화면에서는 담당자·상태·진행률이 값으로만 보이고 수정할 수 없습니다.
  일정을 공유할 때는 이 주소를 알려 주세요.
- 편집은 /admin 에서 비밀번호를 넣고 들어갑니다. 로그인은 12시간 유지되고
  헤더의 [로그아웃] 으로 바로 풀 수 있습니다.
- 저장은 로그인한 사람만 됩니다. 서버에서도 막으므로 주소만 안다고 고칠 수 없습니다.
